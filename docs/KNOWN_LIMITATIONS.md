# NeoVax-Agent: Known Limitations

**Status:** Pre-clinical research prototype — MVP phase  
**Last updated:** 2026-04-27  
**Applies to:** All versions prior to production release

> This document is an honest accounting of what NeoVax-Agent currently cannot do.
> No omissions. Every limitation listed here is intentional or in-scope for future work.

---

## 1. Pipeline is Mock-Only

All bioinformatics tool execution is simulated. No real variant calling, read alignment,
MHC binding prediction, or RNA quantification is performed. The pipeline framework
(Steps 1–7) wraps shell adapters that return synthetic output unless a real tool binary
is installed and configured. Production use requires:

- BWA / BWA-MEM (alignment)
- GATK Mutect2 (variant calling)
- Ensembl VEP (annotation)
- pVACtools / NetMHCpan (MHC binding)
- STAR / Salmon (RNA-seq)

See `docs/BIOINFORMATICS_ADAPTER_GUIDE.md` for installation instructions.

---

## 2. No Real Clinical Validation

NeoVax-Agent has not been validated in any clinical or pre-clinical trial setting.
All outputs — including candidate antigen rankings, evidence levels, and report summaries —
are based on mock scores and synthetic data. They have no established clinical validity,
sensitivity, or specificity.

---

## 3. SQLite Only — Not Production-Grade

The default database is SQLite (single-file, single-writer). This is suitable for local
development and single-researcher use only. Known limitations:

- No concurrent write access
- No replication or failover
- Unsuitable for multi-user or networked deployments
- WAL mode enabled but not tuned for high throughput

PostgreSQL support is planned but not yet implemented.

---

## 4. No Authentication or Authorization

There is no user authentication, session management, or role-based access control.
Any process with network access to the API can read, write, or delete data.
Do not expose the API on a public network. The API is designed for local loopback
(`localhost`) use only.

---

## 5. AlphaFold Backends Are Stubs

All AlphaFold backends except `mock` require external tool installation:

- `colabfold` / `local_colabfold`: requires ColabFold + MMseqs2
- `alphafold2_local`: requires a full AlphaFold2 installation with model weights
- `alphafold3_local`: AlphaFold3 access is restricted; no public weights available
- `alphafold_server`: requires Google DeepMind API access

The `mock` backend returns plausible-looking synthetic confidence scores (pLDDT, PTM)
but does not compute real structures.

---

## 6. No Real MHC Binding Prediction

Binding affinity scores (`netmhcpan_ic50_nM`, `binding_rank`, `immunogenicity_score`)
are entirely synthetic. NetMHCpan, MHCflurry, and similar tools are referenced in
configuration but not invoked unless installed locally. Mock scores should not be
interpreted as real predictions.

---

## 7. Not FDA/EMA Approved — Not for Clinical Use

NeoVax-Agent is a **research coordination tool only**. It is:

- Not a medical device
- Not approved by the FDA, EMA, or any other regulatory body
- Not validated for diagnostic or therapeutic decision-making
- Not intended to be used for or near clinical patient care

Every report generated by the system carries an explicit disclaimer:
_"Research candidate only — not administerable."_

Misuse of this software in a clinical context may violate medical device regulations
and professional ethics requirements.

---

## 8. Single-User Only

The platform is designed for a single researcher or small local team. There is no:

- Multi-tenancy
- Per-user data isolation
- Audit log separation by user
- Concurrent editing safeguards

---

## 9. Demo Data Is Synthetic

All demo cases, variants, candidate antigens, and scores created via `demo.py` or
`seed_demo.py` are entirely fictional. They are designed to demonstrate UI/API behavior,
not to reflect real canine or human oncology cases.

---

## 10. Ethics Templates Are Not Legal Advice

Consent forms, ethics packages, and compassionate use checklists generated by the system
are **templates only**. They must be reviewed by:

- A licensed veterinarian or physician (as appropriate)
- An institutional ethics board or IRB
- Qualified legal counsel

They are not legal documents and confer no regulatory compliance.

---

## 11. Privacy Redaction Is Best-Effort

The redaction and de-identification features (`RedactionLevelEnum`) perform field-level
masking but do not guarantee HIPAA, GDPR, or equivalent compliance. No formal privacy
impact assessment has been conducted.

---

## 12. No Automated Testing of Real Tool Outputs

All tests use in-memory SQLite with mocked outputs. No integration tests against
real bioinformatics tools, real genome references, or real sequencing data exist yet.

---
